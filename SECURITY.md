# Security Policy

## Supported versions

Only the latest `main` branch is supported. Fixes are not backported.

## Reporting a vulnerability

Please do not report security problems in public issues.

Report them privately through GitHub: open the repository's **Security** tab and use the **Report a vulnerability** button. Alternatively, email vitanbalint@gmail.com.

Please include a description of the issue, steps to reproduce it and the impact you expect. You can expect an acknowledgement within a week.

Note that this is a concept prototype with no authentication and no user data; see "Status and limitations" in the README.
